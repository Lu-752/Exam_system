# 考试系统 · 高保真原型说明

> 纯静态 HTML 原型（无后端、无构建依赖），用于确认信息架构与页面布局。
> 所有数据均为**演示用的假数据**，页面中的查询/按钮暂未接真实逻辑。

## 如何查看

直接双击打开 `index.html`（推荐 Chrome / Edge），或选中文件右键用浏览器打开。
页面之间通过顶栏、侧边栏互相跳转，无需启动服务器。

## 导航结构（v2 已按需求调整）

- **顶栏**：只放「学习中心」（回首页）和「系统设置」（进入系统管理模块，默认落地用户管理），不再重复侧边栏内容；右侧为消息铃铛 + 管理员头像
- **左侧导航**（全站统一）：
  - 首页（`index.html`）
  - 学员中心 → 考试中心、报名中心、练习中心、个人中心
  - 考试中心 → 按业务流程排序：大纲管理 → 题库管理 → 试题管理 → 组卷策略 → 试卷管理 → 考试计划 → 考试报名 → 考试监控 → 交卷记录 → 考试阅卷
  - 学习中心 → 学员管理、成绩统计、成绩分析（后两者为占位）
- **系统管理模块**（顶栏「系统设置」进入）：
  按需求，该模块页面**不显示左侧全局导航**（首页/学员中心/考试中心/学习中心归「学习中心」展示），
  只保留页面内左侧的「系统管理」二级菜单栏：角色管理、组织机构、用户管理、字典管理、系统参数、专区管理
- **首页**：欢迎横幅 + 数据概览 4×3 网格（原 3 张统计卡一行已按需求删除）

## 考试中心交互明细（按《考试中心使用说明》实现）

- **弹窗框架**：全站通用 `.mask/.modal`，支持 `data-modal` 打开、`data-close`/点遮罩关闭、`data-title` 动态标题；删除类操作为二次确认框；保存/确定类操作有 toast 反馈
- **大纲管理**：添加/编辑弹窗含大纲名称、基本信息、知识要求、技能要求、考核鉴定点
- **题库管理**：筛选含考试大纲/名称/推荐状态；弹窗含大纲、职业等级、排序、推荐开关
- **试题管理**：题型分段切换（单选/多选/判断/填空/问答/题冒题）；选项编辑器支持正确答案开关、上移/下移/删除/添加；判断题为正确答案单选；导入弹窗含模版下载与格式说明；批量设置分数；试题纠错申请列表（可点「已处理」闭环）
- **组卷策略**：策略详情编辑器（题型/单题分数/分数合计 + 排序删除），满分与启用开关
- **试卷管理**：组卷方式单选切换（手动组卷提示 / 自动组卷选策略+题库）；「试题管理」打开题库选题弹窗（勾选试题）；公开练习/竞赛/高级组卷策略开关
- **考试计划**：添加弹窗含考试次数、IP 限制、开始/结束时间及 10 个配置开关（公开考试/公开报名/防作弊/阅卷隐藏信息/多人阅卷/发回重考/自动交卷/显示成绩/可见题目/显示答案）；调整顺序弹窗
- **考试报名**：新增弹窗（搜索+人员勾选）；批量导入弹窗双页签（导入文件 .xlsx / 用户群组导入）
- **考试监控**：批量延长时间、暂停考试（确认）、强制交卷（确认）、发送消息弹窗
- **交卷记录**：批量发布成绩（隐藏答案/不隐藏答案两种模式）、批量取消发布、计算成绩、更多导出下拉（成绩/明细/报告/试卷）、查看试卷弹窗（题目+考生答案+正确答案+得分）
- **考试阅卷**：批阅试卷弹窗（打分+评语+评分）
- **阅卷教师**：完整列表页，添加弹窗可勾选需审阅的试题范围

## 学员端 · 考试中心交互明细（`student/exam-center.html`）

- **双页签**：公开考试 / 报名考试，顶部筛选栏（考试状态等）+ 查询/重置
- **考试卡片**：状态标签（进行中 / 未开始 / 已结束）、信息行（时长 · 满分 · 及格 · 题量 · 可考次数）、
  mini 标签（防作弊 / 交卷显示成绩 / 交卷显示答案）、操作按钮（立即考试 / 立即报名 / 查看成绩 / 未开始禁用）、非公开报名紫色标签
- **考试详情弹窗**：展示考试信息与说明，「进入考试」跳转答题界面（弹窗间跳转自动重置并启动倒计时）
- **答题界面**：
  - 顶栏：考试名称 + 题型标签 + 倒计时（30 分钟，≤5 分钟变红，时间到自动交卷并 toast）+ 交卷 + 关闭
  - 左侧题目区：单选题 / 多选题 / 判断题 / 问答题（文本域），选项点击即作答（多选可多选再取消）
  - 右侧答题卡：4 格，蓝色 = 已作答、当前题高亮，点击格子跳转对应题
  - 底部：上一题 / 下一题（首题禁用上一题、末题禁用下一题）+ 进度「第 X / 4 题」
- **交卷确认**：动态提示——「还有 N 道题未作答，确认交卷吗？」（N 红色高亮）或「所有题目均已作答，确认交卷吗？」；「再检查一下」返回继续答题
- **成绩结果**：大号分数 + 正确题数（X / 4）+ 及格状态（及格绿色 / 不及格红色，及格线 60 分）；
  「查看答案」展开各题参考答案与考生答案（按钮切换为「收起答案」）
- **报名流程**：立即报名 → 报名确认弹窗 → 确认报名后触发按钮就地替换为「已报名」灰色标签
- **防作弊**：答题中切换浏览器标签页（visibilitychange）弹出「⚠ 检测到切屏行为，系统已记录」toast

## 通用交互层（P0/P1 已补齐，2026-10-21）

以下交互在所有页面真实生效，非演示 toast：

| 能力 | 行为 |
|---|---|
| 筛选查询 | 按标签自动映射表头列，输入即时包含匹配；支持表格与卡片列表（报名中心） |
| 重置 | 清空筛选栏全部输入框/下拉并恢复显示 |
| 分页 | 真实翻页（每页 5 条），筛选后自动重算页数与「共 N 条」 |
| 全选/批量 | 表头全选联动行勾选；批量发布成绩/批量取消发布对勾选行真实改状态 |
| 新增 | 工具栏「添加」打开弹窗，保存后克隆末行追加到列表（字段自动清空） |
| 编辑 | 行内「编辑」打开弹窗并按标签→列名自动预填，保存后回写该行 |
| 删除 | 行内「删除」打开二次确认，确认后该行真实移除 |
| 行内操作 | 成绩统计支持行内发布/取消发布，状态标签即时变色 |
| 导出 | 成绩统计/交卷记录等表格真实导出 UTF-8 BOM 的 CSV（Excel 可直接打开） |
| 导入 | 上传弹窗选择文件后显示文件名并高亮边框 |
| 顶栏 | 消息铃铛下拉（未读红点/单条已读/全部已读）、头像下拉（个人中心/退出登录） |

**弹窗预填规则**：`.m-label` 字段名经归一化（去 `*`、序号、空白）后匹配表头列名，
支持别名（如「考试试卷→试卷名称」「考试时长（分钟）→考试时长」）；匹配不到列的字段不参与预填。

## P2 考试业务规则（2026-10-21 补齐，全部可点击交互）

> 设计约定：跨页面共享状态（监考联动、计划配置）通过 `localStorage` 的两个键传递——
> `exam_proctor`（监考消息/暂停/强制交卷：消息与强制交卷为「事件」，用自增 `msgId`/`forceId` 标记；
> `paused` 为「状态」）与 `exam_cfg`（计划级配置：`shuffle`/`showScore`/`showAnswer`/`min`）。
> 同一浏览器内打开管理端与学员端页面即可看到联动；控制台亦可直接调用
> `window.__proctor.send/pause/resume/force` 演示。

### 学员端 · 考试规则（`student/exam-center.html`）

- **考试次数拦截**：卡片显示「已考 N 次」；次数用完的考试按钮就地替换为灰色不可点「次数已用完」；
  每次交卷（含自动交卷/强制交卷）消耗一次次数并实时更新卡片
- **试题/选项乱序（防作弊）**：配了「试题顺序打乱」的考试（如电工考试）进入答题界面自动打乱题目、
  选项与答题卡顺序（题号自动重排，`data-q` 身份不变，已作答内容不丢）；顶栏「乱序」按钮可随时重新洗牌
- **最短答题时长**：顶栏显示「最短 N 分钟」与已答时长；未满时长点交卷会被拦截并 toast 提示，
  交卷按钮上实时显示「交卷（mm:ss）」倒计时，倒计时归零后才允许交卷
- **计划结束自动交卷**：顶栏「模拟到点」按钮快进到计划结束时间，系统自动交卷并 toast「已到计划结束时间…」
- **成绩/答案可见性联动**：交卷结果弹窗按配置显示/隐藏成绩与答案——隐藏成绩时显示「本考试成绩尚未公布」，
  隐藏答案时隐藏「查看答案」按钮与答案列表并提示「本考试设置为交卷后不显示答案」

### 监考联动（`admin/monitor.html` ↔ 学员端答题界面）

- **发送消息**：监考端「发送消息」弹窗自动带入该考生姓名，发送后学员端答题界面顶部滑出监考消息横幅（可关闭）
- **暂停考试**：确认后该行状态变「已暂停」、操作列换成「恢复考试」；学员端答题界面被全屏暂停层锁定，
  倒计时停止、无法作答；恢复后倒计时继续并 toast「考试已恢复，倒计时继续」
- **强制交卷**：确认后该行状态变「已交卷」、操作列只剩「查看试卷」；学员端立即自动交卷并进入成绩结果

### 发回重考（`admin/records.html`）

- 交卷记录操作列新增「发回重考」→ 弹窗选择时长模式（重置考试时长 / 保留剩余时长）→ 确认后该行
  阅卷状态变「已发回重考」（紫色）、发布状态变「未发布」、操作列收敛为「查看试卷」

### 多人阅卷平均分（`admin/marking.html`）

- 批阅弹窗支持双评分员分别打分，双方均打分后实时计算并展示平均分；「阅卷时隐藏考试信息」开关
  默认开启，考生姓名显示为「刘**」，关闭后显示完整姓名；评分提交 toast 展示平均分

### 计划配置持久化（`admin/exam-plan.html` → 学员端）

- 添加/编辑计划弹窗新增可持久化配置：「试题乱序（题目与选项顺序打乱）」开关、「最短答题时长（分钟）」输入；
  「是否交卷显示成绩 / 是否交卷显示答案」开关状态写入 `exam_cfg`，学员端交卷结果按配置显示
- 交卷记录「批量发布成绩」弹窗选择「隐藏答案 / 不隐藏答案」并发布后，同样改写答案可见性配置
