# STORY — 考试系统操作演示材料

受众：接手系统的人（管理员、实施、学员端使用者）。
场合：**操作培训 / 交接演示**（约 20 分钟），边讲边在系统里点，讲完对方能自己走一遍。
目标：不是说服，是让对方会操作。

## 叙事线（按真实操作顺序，不按功能重要性）

1. **封面**：考试系统 / 十三个动作，走完一场考试。
2. **目录**：13 步一览，标出每步在第几页；说明前 11 步管理员视角，后 2 步学员视角。
3. **登录**：一个地址、两种角色（图形验证码、菜单差异）。
4. **首页**：先看什么——规模数、运行数、待办入口。
5. **建大纲**：骨架先行，题才有地方挂。
6. **建题库**：录一次，之后只挑不抄；六种题型与解析。
7. **组卷策略**：把题型配比存成模板。
8. **试卷管理**：策略出卷 → 人工调题 → 发布。
9. **考试计划**：时间、试卷、参考范围；状态流转与「发布成绩」开关。
10. **报名审核**：要审核的地方在哪、通过/拒绝、允许取消。
11. **考试监控**：一屏看进度、找异常、强制交卷。
12. **考试阅卷**：主观题逐题给分，保存即汇总。
13. **交卷记录**：谁交了、交了什么、跳转复核。
14. **学员端（报名与答题）**：报名、倒计时、自动保存、幂等交卷。
15. **学员查分**：等发布、看总分、逐题复盘。
16. **收尾**：账号怎么给、文档在哪、出问题带什么来找。

## 讲法

- 每页固定「入口路径 → 三步 → 一条提示」，讲一步点一步，不念屏幕上的字
- 截图都是真实数据（张娟 / 90 分 / 1 次切屏），现场可核对
- 学员端两页建议让听众自己扫码/登录操作一遍
