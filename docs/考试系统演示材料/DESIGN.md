# DESIGN — 考试系统操作演示材料

版本 v3：**纯操作演示**。整本只回答一个问题——「这个功能在哪里点、点几下、点完什么样」。
不再讲产品定位、不讲流程价值、不放收尾口号。

## 画布与栅格

- 画布 1280 × 720（16:9），单位 px（1px = 9525 EMU）
- 左右边距 80，内容宽 1120
- 页眉区：编号 + 环节名 y = 58；标题 y = 86（30px）；入口路径 y = 138（12px）
- 内容区：y = 178 ~ 620
- 页脚：左侧环节名（11px `#B0B4BD`），右侧 `NN / 16`，基线 y = 668

## 色板（灰阶 + 一处深蓝）

| 角色 | 色值 | 用法 |
|---|---|---|
| Ink | `#17191E` | 标题、步骤名 |
| Body | `#4A4F5A` | 步骤说明 |
| Muted | `#8C919C` | 入口路径、提示行 |
| Faint | `#B0B4BD` | 页脚 |
| Hairline | `#DCDEE3` | 截图边框、分隔线 |
| Hairline soft | `#EDEFF2` | 目录行分隔 |
| Deep | `#1F3A5F` | 步骤编号、封面竖条、收尾底线（每页仅此一处） |

白底全局统一，不做深浅交替；截图里产品自身的蓝色是「实拍」，不属于版面用色。

## 字体

`Microsoft YaHei`（中英混排统一）。字号：封面标题 56 / 页标题 30 / 目录标题 32 /
步骤名 14 / 步骤说明 11.5 / 入口路径 12 / 页脚 11。行高：标题 1.2，说明 1.6–1.65。

## 三种版式（按截图长宽比选，不随意换）

1. **split-right**（图右文左）——截图 1.2 ≤ 比例 ≤ 2.2
   文字列 x 80 宽 500，图 x 620 宽 580，图区垂直居中（170–620）。
2. **split-left**（图左文右）——同比例，用于打散节奏
   图 x 80 宽 580，文字列 x 700 宽 500。**注意文字不要压到图上（x 必须 ≥ 660+40）**。
3. **band**（图上文下）——截图比例 > 3（列表页大多是宽条带）
   图宽 1120（比例 < 3.7 时按高 300 反算宽度并居中），顶部 y = 178；
   三栏步骤 y = max(178 + 图高 + 46, 440)，栏宽 346，间距 40；提示行在步骤下方 108。

步骤统一 3 条，格式：`0N`（Deep，11px，加粗）＋ 空格 ＋ 步骤名（Ink 14px 加粗），
下一行说明（Body 11.5px）。编号在这里是真序号（操作顺序），不是装饰。

## 内容规则

- 每页必须有「入口路径」，写真实菜单名（与左侧菜单一致：考试中心 → 题库与试题）
- 步骤动词开头：新建 / 选择 / 保存 / 发布 / 点开
- 每页最多一条「提示」，写坑或前置条件，不写卖点
- 截图必须是真实数据跑出来的界面，不做空页、不做示意图

## 生成方式

`python scripts/build_deck.py` → 直接输出 `考试系统演示材料.pptx`（16 页）。
内容全部写在脚本的 `INDEX` / `SLIDES` 数据里，改文案只改数据，不动版式。

> `slides/*.slide` 是 v2（产品介绍版）的 SlideDSL 源文件，已归档不再使用。
