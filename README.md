# 考试系统

在线考试全流程系统：大纲 → 题库 → 组卷 → 考试计划 → 在线考试 → 实时监考 → 阅卷 → 成绩分析。

> 详细说明见 [`系统说明文档.md`](系统说明文档.md)（架构、模块、接口、数据模型、质量验证）。

## 启动

```bash
# 前端（:5173）
npm install
npm run dev

# 后端（:8080）
scripts\backend.cmd run
```

- 管理端：http://localhost:5173/#/login
  - 管理员：`admin / Mima3700%`（全部后台）
  - 学员：`student / Mima3700%`（仅考试中心，可在线答题、看成绩）
- 后端健康检查：http://localhost:8080/actuator/health
- H2 控制台（dev profile）：http://localhost:8080/h2-console （JDBC URL 见 `application.yml`）
- 全链路冒烟（需后端已启动，建议空库按序执行）：
  `smoke_m3.py`（考试主链路）→ `m4`（系统管理+权限）→ `m5`（练习+报名）→ `m6`（组卷+交卷记录）→ `m7`（题冒题+成绩闸门）→ `m10_org`（组织机构）→ `m12_import`（批量导入）→ `m14_cheat`（切屏检测）→ `m15_misc`（大纲/字典/参数）→ `m16_outline_link`（大纲↔题库联动）
- 演示自动登录：前端开发模式 `?demo=1`（管理员）/ `?demo=student`（学员）

## 已知限制

- 令牌存储是进程内 Map，多节点部署前需换 Redis（`TokenStore` 接口已隔离）。
- 本地 dev 用 H2（PostgreSQL 兼容模式），生产 profile `pg` 指向 PostgreSQL 16。
- Element Plus 按需引入待优化（当前全量引入）。
- 权限强校验（`@PreAuthorize`）覆盖平台域与考试域管理接口，部分读接口暂只要求登录。
